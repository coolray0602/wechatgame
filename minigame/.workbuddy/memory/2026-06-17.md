## 炸弹 3 的倍数问题修复
- **根本原因**：炸弹算法未计入卡槽中的牌，导致卡槽需要的牌被误清，关卡卡死。
- **修复**：
  1. 计算剩余总数时纳入 slotCards
  2. nearby 优先选择卡槽不需要的牌
  3. extra 计算用公式 (slotCnt + remainingBoard) % 3
  4. 排除 willRemove 状态的牌（上次炸弹残留）

## 动画期间禁止操作
- 新增 `isAnyCardMoving()` 辅助函数，检查所有动画数组(entrance/bomb/active/throwBack/shuffle/action/throwAction/dance)以及 stackCards 中 isAnimating 的牌
- 守卫点：
  - `onCardClick`：用 `isClickBlocked()`，允许飞入卡槽动画期间点击其他卡牌
  - `useBomb`：用 `isAnyCardMoving()`，所有动画期间禁止炸弹
  - shelf 道具柜点击：用 `isAnyCardMoving()`，所有动画期间禁止道具
  - onTouchStart 卡牌点击区：用 `isClickBlocked()`，允许飞入卡槽动画期间点击其他卡牌
- `isClickBlocked()` 排除 `activeAnimations`：卡牌飞入卡槽时允许继续操作，提升流畅度

## 动画阻塞细化分析
- `actionAnimations`（三消角色行走）和 `throwActionAnimations`（扔回精灵）是从两个阻塞函数中移除——它们是纯视觉精灵图渲染，不碰卡牌状态，不会造成 bug
- 最终阻塞矩阵：
  - **点击卡牌** (isClickBlocked)：只阻止 entrance / bomb / throwBack / shuffle / dance（这些会改变卡牌位置或状态）
  - **道具使用** (isAnyCardMoving)：在以上基础上额外阻止 activeAnimations（飞入卡槽时用道具可能造成状态不一致）
